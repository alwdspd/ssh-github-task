# Настройка SSH-аутентификации для GitHub

## 1. Проверка наличия SSH-клиента

Проверено наличие SSH-клиента в Windows с помощью команды:

```powershell
ssh -V
```

SSH-клиент установлен и готов к использованию.

## 2. Генерация пары SSH-ключей

Для подключения к GitHub была сгенерирована пара ключей алгоритма ED25519:

```powershell
ssh-keygen -t ed25519 -C "email@address.com"
```

При генерации ключа была задана парольная фраза (passphrase) для защиты приватного ключа.

Созданы следующие файлы:

- `id_ed25519` — приватный ключ. Хранится локально и не передаётся третьим лицам.
- `id_ed25519.pub` — публичный ключ. Используется для добавления в GitHub.

Путь хранения ключей: `C:\Users\username\.ssh\`

## 3. Добавление публичного ключа в GitHub

Содержимое публичного ключа было получено командой:

```powershell
Get-Content ~/.ssh/id_ed25519.pub
```

Публичный ключ добавлен в аккаунт GitHub:

Settings → SSH and GPG keys → New SSH key.

Название ключа: `My Windows PC`.

## 4. Проверка SSH-подключения к GitHub

Для проверки подключения была выполнена команда:

```powershell
ssh -T git@github.com
```

В результате GitHub подтвердил успешную аутентификацию:

```text
Hi alwdspd! You've successfully authenticated,
but GitHub does not provide shell access.
```

Это подтверждает успешную настройку SSH-аутентификации.

## 5. Работа с репозиторием через SSH

Репозиторий был клонирован с использованием SSH-адреса:

```powershell
git clone git@github.com:alwdspd/ssh-github-task.git
```

После клонирования был создан файл README.md и подготовлен коммит.

Для отправки изменений использовались команды:

```powershell
git add .
git commit -m "Добавлено описание настройки SSH"
git push
```

Изменения отправлены в удалённый репозиторий GitHub.

## 6. Заключение

В ходе выполнения задания:

- Проверена работа SSH-клиента.
- Сгенерирована пара SSH-ключей ED25519.
- Публичный ключ добавлен в аккаунт GitHub.
- Проверена успешная SSH-аутентификация.
- Выполнено клонирование репозитория через SSH.
- Создан коммит и отправлены изменения через Git.

Таким образом, настроена работа с GitHub посредством SSH без необходимости ввода пароля аккаунта GitHub при каждой операции отправки изменений.
